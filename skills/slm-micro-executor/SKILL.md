# Skill: slm-micro-executor

## Purpose
Execute atomic task plans generated by atomic-task-planner. 1 step = 1 tool call, <=150 tokens. Extends slm-local-prompt-design for execution.

## Context
SLM on Z600 (2x Xeon E5620, 24 GB DDR3) requires micro-tasks. This skill executes the JSON plans from atomic-task-planner.

## Execution Model

### Step Format
`json
{
  "step": 1,
  "tool": "read|write|edit|bash|grep|glob",
  "params": { ... },
  "verify": "command_or_pattern",
  "max_tokens": 150
}
`

### Execution Loop
1. Read plan from .kilo/plan/execution_plan.json
2. For each step:
   a. Construct prompt per slm-local-prompt-design rules
   b. Execute tool call
   c. Run verification
   d. If verify fails -> retry (max 2) or abort
   e. Log result to .kilo/execution/execution_log.yaml
3. Report summary: steps_ok, steps_failed, tokens_used

## Supported Tools

| Tool | Prompt Template | Verification |
|------|-----------------|--------------|
| 
ead | Read {path}. Verify: {verify} | Content contains pattern |
| write | Write {path} with content. Verify: Test-Path | File exists |
| dit | Edit {path}: replace '{old}' with '{new}'. Verify: diff | Diff shows change |
| ash | Run: {command}. Verify: {verify} | Exit code 0 + output match |
| grep | Search {pattern} in {path}. Verify: count>0 | Matches found |
| glob | Find {pattern} in {path}. Verify: count>0 | Files found |

## Token Budget
- Per step: <= 150 tokens (prompt + expected output)
- Total plan: <= 1000 tokens
- If exceeded -> split plan, execute sequentially

## Retry Logic
- Max 2 retries per step
- On failure: log error, continue to next step (if non-critical)
- Critical steps (marked critical: true) -> abort plan on failure

## Command
`powershell
python -m tools.slm_executor --plan .kilo/plan/execution_plan.json --log .kilo/execution/execution_log.yaml
`

## Output Log Format

    tool: read

  - step: 2

    status: OK
    tokens: 89

`

## Anti-patterns
- Steps > 150 tokens (must split in planner)
- Missing verification (no feedback loop)
- Not logging execution (no audit trail)
- Retrying indefinitely (max 2)
- Executing without plan (ad-hoc)
