# KEEL — Knowledge Encoding & Execution Language (v0.5)

## Domaine et périmètre

KEEL est la **langue de la complexité vivante** de l'écosystème gerivdb (L1b).
Cinq blocs, de la fondation ternaire jusqu'à la rigueur catégorielle :

| Couche | Bloc | Adresse | Nouveau v0.5 |
|--------|------|---------|-------------|
| Fondation | Trit-Node · ◈ · TQL · PLIX×5 | base-243 + LYCOS + VDB | — |
| Histoire | **◈-DAG** | dérive, replay, fantômes | — |
| Métacognition | **META-LOOP** | BRAIN s'observe via KEEL | — |
| Métamorphose | **VERSE-MORPH** | 𝔽, η, ⊣, 𝕋 Grothendieck | ✅ |
| Plasticité | **HARNESS** | plug/unplug BRAIN + BLO | — |

KEEL n'est pas un exécuteur — DSL pur. Exécution = BRAIN.

## Règles critiques (10 actives)

- **R1** — KEEL = DSL. Exécution = BRAIN. `[CRITICAL]`
- **R2** — T1-seul INTERDIT. Minimum T1+T3 croisés. `[CRITICAL]`
- **R3** — Tout ◈ → IntentHash dans NEXUS. `[HIGH]`
- **R4** — TQL + META-LOOP + HARNESS → gate D4 pour promotion NEXUS. `[CRITICAL]`
- **R5** — Noms dans [NOM] validés par ONTOLOGY. `[HIGH]`
- **R6** — META-LOOP ⟳ : agent ne peut pas auto-valider. `[CRITICAL]`
- **R7** — VERSE-MORPH ◈↗ → ⊷! FLUX + IntentHash. `[HIGH]`
- **R8** — HARNESS ⊲ (BLO) → ⊷! FLUX. Zéro auto-modification BRAIN. `[CRITICAL]`
- **R9** — Foncteur 𝔽 doit déclarer ≋ composition + ≋ identite. Partiel interdit. `[HIGH]`
- **R10** — Adjonction Branch⊣Merge : coünité (merge) → ⊷! FLUX. `[CRITICAL]`

## Bloc VERSE-MORPH v0.5 (Foncteurs)

### Foncteur covariant
```keel
𝔽 [political_compass_verse → urban_ontology_verse] {
  obj: (S,M,E,I) ↦ (x,y,z)_urban
  mor: relation_politique ↦ causalite_urbaine
  ≋ composition   # 𝔽(g∘f) = 𝔽(g)∘𝔽(f)
  ≋ identite      # 𝔽(id_A) = id_𝔽(A)
  ≋ Poincaré      # β₀=1, β₁=0, χ∈[1,2]
}
```

### Foncteur contravariant (rétroaction)
```keel
𝔽ᵒᵖ [urban_ontology_verse → political_compass_verse] {
  mor: effet_urbain ↦ cause_politique   # flèches renversées
  ≋ composition_op   # 𝔽ᵒᵖ(g∘f) = 𝔽ᵒᵖ(f)∘𝔽ᵒᵖ(g)
}
```

### Transformation naturelle η
```keel
η: 𝔽 ⟹ 𝔾 {
  composante_A: [political_compass:+] ↦ cohérence_naturelle
  ≋ carré_commutatif   # η_B ∘ 𝔽(f) = 𝔾(f) ∘ η_A
  ≋ Poincaré
}
```

### Adjonction Branch ⊣ Merge (champ des possibles)
```keel
𝔹ranch ⊣ 𝕄erge {
  unité:     id ⟹ 𝕄erge ∘ 𝔹ranch   # créer branche
  coünité:   𝔹ranch ∘ 𝕄erge ⟹ id  # merger → ⊷! FLUX (R10)

  𝔹ranch [KEEL:design:V5] {

  }
}
```
